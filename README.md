# 📊 Data Analyzer and Transformer Program
## 📌 Project Overview
### The Data Analyzer and Transformer Program is a Python-based menu-driven application designed to perform different operations on a dataset entered by the user. This project demonstrates the use of functions, recursion, lambda functions, built-in functions, sorting techniques, loops, and multiple return values in Python.
### The program allows users to input numerical data, analyze it, filter values, sort numbers, calculate factorials, and display statistics in an organized way.
## 🎯 Objectives of the Project
### • To understand and implement Python functions
### • To use built-in functions for data analysis
### • To implement recursion using factorial calculation
### • To apply lambda functions for filtering data
### • To perform sorting operations
### • To return multiple values from functions
### • To build a menu-driven Python application
## ⚙️ Features of the Program
### 1️⃣ Input Data
#### Users can enter numerical values separated by spaces, which are stored in a list for further operations.
### 2️⃣ Display Data Summary
#### The program displays:
##### Total number of elements
##### Minimum value
##### Maximum value
##### Sum of all values
##### Average value
### 3️⃣ Calculate Factorial (Recursion)
#### The user can calculate the factorial of a number using a recursive function.
### 4️⃣ Filter Data by Threshold (Lambda Function)
#### The program filters and displays values greater than a user-defined threshold using a lambda function.
### 5️⃣ Sort Data
#### The dataset can be sorted in:
##### Ascending Order
##### Descending Order
### 6️⃣ Display Dataset Statistics
#### The program returns and displays:
##### Minimum value
##### Maximum value
##### Sum of values
##### Average value
### 7️⃣ Exit Program
#### Users can safely exit the application.
